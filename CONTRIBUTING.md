# Contributing

Thanks for your interest in dmgCtrl.

**The project isn't accepting pull requests yet.** It is still changing quickly, and a pull request from outside the project is closed automatically with a comment pointing here. That isn't a judgement on the change: it just can't be reviewed and merged yet.

**No bounties are offered.** Some tickets mention "Bounty", but that is a keyword in Star Wars: Unlimited, not a reward.

## How to help today

- **Play the game** at [dmgctrl.app/sealed](https://dmgctrl.app/sealed) and see what feels wrong.
- **Report bugs with the in-app bug button.** Turn on **Show the bug report button** in **Settings**, then use the bug button in the game header. It copies a full report of the game so far to your clipboard and opens GitHub's new-issue page: paste and submit. The report lets the game be replayed exactly, which is far more useful than a description alone.
- **Open an issue** to say you'd like to contribute, and what you're interested in. When the project is ready for contributions, that is how the first contributors will be found.
